INSTALL TRENDWATCH STEP 15

1. Extract ZIP.
2. Copy folder trendwatch ke:
   C:\laragon\www\

3. Pastikan struktur folder seperti ini:
   C:\laragon\www\trendwatch\index.php
   C:\laragon\www\trendwatch\setup.php
   C:\laragon\www\trendwatch\auth\login.php
   C:\laragon\www\trendwatch\admin\dashboard.php

4. Buka di browser:
   http://localhost/trendwatch/setup.php

5. Login:
   http://localhost/trendwatch/auth/login.php

6. Akun default:
   Email: admin@gmail.com
   Password: admin123

7. Jika muncul error no such table, buka setup.php sekali lagi.
   Aplikasi ini juga sudah membuat tabel otomatis melalui config/database.php.

8. Jika Google Trends Sync gagal, aktifkan ekstensi PHP:
   extension=pdo_sqlite
   extension=sqlite3
   extension=simplexml
   extension=curl

9. Restart Laragon setelah mengubah php.ini.

FITUR STEP 15
- Landing page baru
- Dashboard lebih modern
- Sidebar final
- Dark mode dan light mode
- Mobile responsive
- Tabel dan form lebih rapi
- Chart mengikuti tema tampilan

STEP 16 - SEO CONTENT BRIEF GENERATOR

1. Jalankan setup.php setelah mengganti file project.
2. Login sebagai admin.
3. Buka menu SEO Brief.
4. Klik Generate pada salah satu tren.
5. Buka detail brief untuk melihat keyword, intent, judul, meta description, outline, FAQ, dan ide konten sosial media.

Catatan:
Fitur ini gratis dan tidak memakai API AI. Semua hasil dibuat memakai template otomatis PHP berdasarkan nama tren, kategori, volume pencarian, keyword terkait, status, dan SEO score.


STEP 17 - AI OPTIONAL
1. Buka http://localhost/trendwatch/admin/ai_settings.php setelah login.
2. Pilih provider AI.
3. Isi API key bila memakai provider cloud.
4. Untuk Ollama, jalankan Ollama di komputer lalu isi endpoint http://localhost:11434/api/generate.
5. Simpan pengaturan.
6. Klik Tes AI Sekarang.
7. Buka SEO Brief lalu Generate atau Regenerate.

Catatan:
- AI tidak wajib aktif.
- Jika AI gagal, sistem otomatis memakai template gratis.
- Aktifkan extension curl di PHP untuk memakai API AI.
